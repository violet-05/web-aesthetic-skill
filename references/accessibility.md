# 无障碍与可用性

## 语义与名称
使用 button 表示动作、a 表示导航，避免 div onclick 替代原生交互。为页面设置 lang，为内容提供 main 和有意义标题。标签应与字段关联，图标按钮有可访问名称，装饰图用空 alt 而非遗漏属性。

## 键盘与焦点
所有核心任务必须不依赖鼠标。Tab 顺序符合阅读顺序，不滥用正数 tabindex。菜单/弹窗打开后焦点有去处，关闭后回到触发点。焦点不能被固定栏遮挡，不能无理由移除 outline。

## 表单与恢复
错误信息说明原因和修复方法，与字段关联，必要时提供错误摘要。成功、失败、加载状态不只靠颜色或旋转图标表达。防止重复提交，但不要永久禁用操作；保留用户已输入内容。

## 感知需求
对比检查需覆盖文字、图标、边界与各种状态；颜色不是唯一编码。尊重减少运动偏好，音视频需要适用字幕或替代信息。页面缩放和文字放大不应导致核心内容丢失。

## 本工具边界
当前检查 alt 存在、文档地标、名称/尺寸/遮挡启发式，以及显式配置的焦点场景；没有实现完整可访问名称算法、屏幕阅读器测试、WCAG 审计或全页对比计算。不能把启发式通过解释为合规。

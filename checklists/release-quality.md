# 发布质量检查清单

每项记录 pass / fail / unknown / skipped，以及证据。清单本身不是自动执行结果。

- [ ] Skill frontmatter 和本地引用通过 skill-check
- [ ] 依赖锁文件存在，主文档命令实际运行
- [ ] 类型检查、代码检查、单元/集成测试与构建均记录结果
- [ ] 正常与缺陷 Fixture 验证真实检测而非只验证无崩溃
- [ ] 声明通过的浏览器引擎均有本轮真实启动证据；未运行引擎保持 unknown
- [ ] matrix 的 partial/timeout/cancel/error 不会被解释为整体通过，所有引擎报告路径可访问
- [ ] 像素基线缺失、尺寸/浏览器版本变化、遮罩缺失与 diff 阈值均有证据，unknown 不计通过
- [ ] touch/tap 与嵌套滚动预算耗尽路径不会伪报通过
- [ ] 报告不把 unknown/skipped/error 计入通过
- [ ] 报告 HTML 对页面文本转义，图片路径受控
- [ ] URL/DNS/重定向与输出边界有测试
- [ ] 截图、诊断与本轮元数据可定位
- [ ] 未上传项目内容，不包含硬编码密钥
- [ ] 明确区分已实现功能与未来像素基线/单命令矩阵/视觉模型/自主修复能力

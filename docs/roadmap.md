# 从本地 Skill 到阶段 C

## 已交付 0.1 / 0.2

设计知识与工作流、真实 Chromium 审查、显式交互、结构化证据、静态 HTML、报告比较与自动化回归。未发布云服务或公共 npm 包。

0.2已补齐有界懒加载滚动、步骤/断言截图、整轮浏览器时限和取消；使用报告schema1.1，保留旧报告同版本对比。

## 下一步：扩展验证而非堆管理后台

1. 完善更多报告迁移与场景前提描述；引入可选择的浏览器矩阵和触屏配置。保持旧报告可读，并验证不同浏览器结果差异。
2. 在0.2有界滚动/懒加载/状态截图基础上增加可选像素基线、嵌套滚动容器和虚拟列表覆盖。区分字体、动态内容与真实回归，不能将像素差直接解释为审美下降。
3. 实现一个可替换 VisualReviewer 适配器。先取得截图上传许可，从环境变量读取凭据，设置超时/重试预算并验证模型输出；标记 ai、置信度及证据，不替代测量事实。
4. 增加人工评审输入与设计目标记录，保持主观评分可解释且未知不自动计满分；支持自定义权重，但避免总分掩盖阻断问题。
5. 实现受控 CodeRepairer：只允许批准文件，先检查未提交改动与备份，产生最小补丁，验证失败可回滚。不能默许部署、数据删除或大量依赖升级。
6. 实现有界编排控制器：理解目标 → 选择修复 → 补丁 → 相同场景复查 → compare → 预算/最大轮数/用户停止。先用独立回归任务验证无回归与停止条件，再扩大自主范围。

## 暂不优先

账户、计费、数据库、远程项目上传、多租户浏览器池与独立 SaaS。任何未来网络/模型功能需显式开启，基础审查继续无密钥可运行。
